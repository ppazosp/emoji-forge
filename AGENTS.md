# Emoji Forge

For emoji and sticker tasks, start at [the skill entry point](skills/emoji-forge/SKILL.md). The directory under `skills/emoji-forge/` is the installable unit. Keep its links, Python package, scripts, shaders, and assets within that directory.

From the checkout root, use `uv run --project skills/emoji-forge forge --help` for the CLI or `uv run --project skills/emoji-forge --extra gpu --extra test pytest -q` for tests.
